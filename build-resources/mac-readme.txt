예배 프레젠테이션 — 맥에서 처음 열기
════════════════════════════════════════════════════

1) 왼쪽의 SermonPresentation 을 오른쪽 '응용 프로그램' 으로 끌어다 놓습니다.

2) 앱을 엽니다.

   ▸ 그냥 열리면 끝입니다. 아래는 읽지 않아도 됩니다.
     (만든 사람이 USB 로 직접 건네준 경우는 대개 그냥 열립니다)

   ▸ "손상되었기 때문에 열 수 없습니다" 가 뜨면 3) 으로.
     ※ 앱은 멀쩡합니다. Apple 공증(유료 개발자 계정)을 받지 않아
       macOS 가 '인터넷에서 받은 것' 표시를 보고 막는 것입니다.


3) 표시를 지웁니다. 두 가지 방법 중 편한 쪽으로.

   ── 방법 A · 함께 든 스크립트 (터미널 입력 없음) ──────────

     이 창의 '맥에서 처음 열기.command' 를 두 번 누릅니다.

     macOS 가 이것도 한 번 막을 수 있습니다. 그러면:
       · [완료] 를 누르고
       · 시스템 설정 → 개인정보 보호 및 보안 → 아래로 내려
         '그래도 열기' 를 누른 뒤
       · 다시 두 번 누릅니다.

   ── 방법 B · 터미널 한 줄 (가장 확실) ─────────────────────

     ⌘ + 스페이스 → '터미널' → 아래 줄을 붙여넣고 Enter.
     아무 것도 안 나오면 성공입니다.

xattr -dr com.apple.quarantine /Applications/SermonPresentation.app


4) 앱을 엽니다. 이 준비는 한 번만 하면 됩니다.
   (새 판을 다시 설치하면 그때 한 번 더)
