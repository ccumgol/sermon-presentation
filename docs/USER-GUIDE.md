## 0. 예배 하루 전 — 준비 순서

1. **예배 순서** 탭에서 유형(주일예배 등)을 고른다
2. **기본 설정** 으로 이 예배의 템플릿·역본·찬양 표시 언어를 한 번 정한다
3. 항목을 채운다 (성경·찬양·교독문·전례문·순서 표시·광고)
4. 예외가 필요한 항목만 그 줄에서 따로 지정한다 (배경·폰트·크기·표시 언어)
5. **템플릿 업데이트**(유형에 굳히기) 또는 **순서 저장하기**(이번 회차 보관)
   — 불러온 순서를 고치는 중이면 **저장하기** 가 그 회차에 바로 저장합니다

> **처음 쓰는 PC 라면**: 설정 탭 → **화면 폰트** 에서 권하는 폰트 두 개가 깔려 있는지
> 먼저 보세요. 없으면 명조를 골라도 고딕이 나가는데 화면은 멀쩡해 보입니다 (5.2 참고).

## 0.1 예배 당일 — 진행 순서

1. 서버 실행 → OBS 브라우저 소스 확인 (상단에 `OBS 1개 연결` 이 떠야 한다)
2. 강사·찬양팀이 볼 화면이 필요하면 **강사 모니터** 를 열어 강단 모니터에 둔다 (6.1)
3. **예배용으로 올리기** — 순서표 전체가 하나의 덱이 된다
4. `→` `Space` 로 진행, `PgDn` 으로 항목 단위 점프
5. 순서를 벗어나 급히 띄울 것은 그 줄을 눌러 단독 송출

> 올린 **뒤에** 항목 설정을 바꾸면 화면이 따라오지 않습니다 — `예배용으로 올리기` 를
> 다시 누르세요. 조정은 올리기 전에 하는 편이 편합니다.

## 1. 예배 순서 탭

가장 많이 쓰는 화면입니다. **한 열**이고, 성경·찬양은 펼쳐서 슬라이드를 고릅니다.

### 1.1 무엇을 누르면 화면에 나가는가 ★

이 탭의 핵심 규칙은 하나입니다 — **나가는 것은 언제나 '슬라이드'** 입니다.
(머리 줄을 누르면 본문이 아니라 **제목 슬라이드**가 나갑니다 — 1.1.1)

| 누르는 것 | 동작 |
|---|---|
| 성경·찬양·교독문·전례문의 **머리 줄** (여러 장) | **펼치기/접기 + 제목 한 줄** (1.1.1) |
| 펼친 **슬라이드 줄** | **송출** |
| 광고·순서 표시·공백 (한 장) | 그 줄이 곧 슬라이드이므로 **송출** |
| 구분(그룹 머리글) | 아무것도 나가지 않음 |

빨간 점 = 지금 송출 중, 파란 테두리 = 커서(보고 있는 곳).

### 1.1.1 항목을 누르면 제목이 나갑니다 ★

성경·찬양·교독문·주기도문·사도신경은 **여러 장**이라, 항목을 먼저 누르고 그 안의 장을
눌러야 본문이 나갑니다. 그래서 **항목을 누르는 순간 제목 한 줄이 화면에 나갑니다** —
회중이 다음을 준비할 수 있습니다.

| 항목 | 화면 |
|---|---|
| 성경 | `창 1:1-6` (적어 넣은 그대로) |
| 찬양 | `새찬송가 1장 만복의 근원 하나님` |
| 교독문 | `교독문 15, 시편 51편` |
| 주기도문·사도신경 | `주기도문` / `사도신경` |

- **접을 때는 나가지 않습니다** — 펼칠 때만
- 제목은 그 항목이 쓸 **템플릿으로** 나갑니다. 곧이어 나올 본문과 같은 자리·같은 모양입니다
- 부담스러우면 **기본 설정 → '항목을 누르면 제목 띄우기'** 를 끄면 됩니다

> 예전에 만든 찬양 항목은 곡집 표기가 없어 **곡 제목만** 나갑니다. 새로 넣는 항목부터
> `새찬송가 1장` 이 붙습니다.

### 1.2 예배 유형과 저장

순서표를 날짜별로 새로 만들지 않습니다. **주일예배·수요예배·새벽기도회·부흥회** 유형을
두고 매주 고쳐 씁니다(처음 실행 시 자동 생성).

맨 위 칸이 **지금 고치는 중인 것**입니다 — 예배 유형이든, 불러온 회차든 여기에 이름이 뜹니다.
그 칸에서 유형과 저장된 순서를 모두 고를 수 있습니다.

**버튼은 열어 둔 것에 따라 달라집니다.**

| 열어 둔 것 | 2번 버튼 | 3번 버튼 |
|---|---|---|
| **예배 유형** | **템플릿 업데이트** — 이 유형의 원본으로 굳힌다 | **순서 저장하기** — 이번 회차를 따로 남긴다 (기본 이름 `날짜 + 유형명`) |
| **저장된 순서** | **저장하기** — 그 회차에 **그대로** 저장한다 (이름을 다시 치지 않는다) | **다른 이름으로 저장** — 원본은 두고 하나 더 만든다 |

| 그 밖 | 동작 |
|---|---|
| **순서 불러오기** | 저장해 둔 회차 목록을 펼친다 (여기서 지울 수도 있다) |
| **＋** | 지금 항목으로 **새 유형**을 만든다 |
| **⧉ ✎ ✕** | 지금 열어 둔 것을 복제·이름 바꾸기·삭제 (유형·순서 모두) |

`저장 안 됨` 줄이 **어느 버튼을 눌러야 어디에 남는지** 알려 줍니다.
같은 이름으로 저장하면 버튼이 **덮어쓰기** 로 바뀌고 경고가 뜹니다.
저장하지 않은 변경이 있는데 다른 것을 열면 확인을 받습니다.

> 탭을 옮겨도(찬양·성경 …) 짜던 순서는 그대로 남습니다. 브라우저를 새로 고쳐도
> 남습니다. 조작 창(탭)을 닫으면 저장하지 않은 편집은 사라집니다.

### 1.3 기본 설정 — 한 예배에 한 번만 정하기

**기본 설정** 버튼을 누르면 이 예배 전체의 기준을 정합니다.

| 정하는 것 | 적용 시점 |
|---|---|
| 성경·찬양·순서 표시·광고 **기본 템플릿** | **송출할 때.** 항목이 따로 지정하지 않았으면 이 값을 쓴다 |
| 성경 **역본**(주·보조)·화면 넘김 | 항목을 **새로 넣을 때** 채운다 |
| 찬양 **언어·줄 수** | 〃 |

템플릿은 나중에 기본을 바꾸면 **따로 지정하지 않은 항목이 모두 따라옵니다.**
역본·언어는 이미 만든 항목을 건드리지 않습니다(본문 설정이 예고 없이 바뀌면 놀라므로).

> **기본 설정에는 따로 저장하는 곳이 없습니다.** 이 값들은 순서표 안에 함께 담겨서,
> 위와 같은 버튼 하나로 저장됩니다 — 예배 유형이면 **템플릿 업데이트**, 불러온 순서면
> **저장하기**. 헷갈리지 않도록 **기본 설정 카드 맨 아래에 같은 버튼을 하나 더 뒀습니다.**
> 설정을 만진 자리에서 그대로 누르면 됩니다.

### 1.4 항목 종류

| 아이콘 | 종류 | 설명 |
|---|---|---|
| 📖 | 성경 | 참조를 넣으면 **추가 전에** 파싱 결과를 보여 준다. 주·보조 역본 선택 (주 + 보조 2 = 최대 3) |
| 🎵 | 찬양 | 번호(`새 305`)·제목·가사로 찾는다. **표시 언어**를 항목마다 고른다 (최대 3) |
| 🙏 | 주기도문·사도신경 | 개역개정 / 개역한글 · 배경 그림 · 폰트(고딕/명조) · 글자 크기 · 화면 넘김(2·4·6줄·전체) |
| 🔁 | 교독문 | **통일찬송가용(76편) / 새찬송가용(137편)** 을 먼저 고른다. 번호나 제목으로 찾는다. **인도자·회중 두 줄이 한 화면**에 나간다 (흰색 / 노란색) |
| 📋 | 순서 표시 | 대표기도·설교 제목·축도 등. 첫 줄=순서 이름, 다음 줄=담당자 |
| 📝 | 광고 | 여러 줄로 쓰면 그대로 나간다 |
| 💬 | 인용구 | **설교 중 띄울 성경 절.** `창 1:1-6` 을 넣으면 **낱개 6줄**이 됩니다 (타이틀 없음 · 한 번 클릭으로 송출 · `↩ 직전으로` 복귀) |
| ⬛ | 공백 | 화면의 글자를 지운다 (블랙과 다름 — 3.2 참고) |
| ▾ | 구분 | 그룹 머리글. **화면에 나가지 않는다** |

- 광고·순서 표시는 **Enter 로 추가**, 줄바꿈은 `Shift+Enter`. 인용구는 성경처럼 **참조 한 줄**
- 순서 표시는 자주 쓰는 이름 10종을 버튼으로 넣을 수 있다
- 모든 항목에 **↑ ↓ ✕**(이동·삭제), 구분에도 있다

### 1.4.0 교독문은 두 벌이 들어 있다 ★

찬송가마다 교독문이 다릅니다. **번호가 같아도 다른 글**입니다.

| 고르는 것 | 편수 | 15번의 예 |
|---|---|---|
| 통일찬송가용 | 76편 | 시편 51편 |
| 새찬송가용 | 137편 | 시편 27편 |

- 교독문 추가 칸 위의 **두 버튼**으로 고릅니다. 버튼에 편수가 함께 나옵니다.
- 기본은 **통일찬송가용**입니다 — 이미 만들어 둔 순서표가 그대로 열리게 하기 위한 것입니다.
- 순서표 목록에서는 새찬송가용에 **`새 `** 가 붙습니다 (`새 교독문 15. 시편 27편`).
- 항목을 고르면 상세 칸에 `새찬송가용 · 15번` 처럼 어느 쪽인지 나옵니다. **여기서는 바꿀 수
  없습니다** — 바꾸면 내용이 통째로 다른 글이 되므로, 다른 쪽을 쓰려면 항목을 다시 넣으세요.
- **화면에는 어느 찬송가인지 나가지 않습니다** (`교독문 15, 시편 27편`). 회중은 그날 무엇을
  쓰는지 이미 알고 있고, '새 교독문' 이라고 나가면 오히려 헷갈립니다.

### 1.4.05 인용구 — 설교 중 띄울 성경 절 ★

**💬 인용구는 성경 절을 낱개로 넣는 기능입니다.** 광고(📝)와 겹치던 자유 글자 기능을
2026-08-20 에 바꿨습니다.

성경(📖)과 무엇이 다른지가 전부입니다.

| | 📖 성경 | 💬 인용구 |
|---|---|---|
| `창 1:1-6` 을 넣으면 | 항목 **하나** (`창 1:1-6`) | 항목 **여섯** (`창 1:1` … `창 1:6`) |
| 목록 줄 | 머리 줄 하나, 펼치면 6장 | 여섯 줄, 각 줄에 **본문이 함께** |
| 펼치기 | `▸` 로 펼쳐서 장을 고른다 | 없다 — **한 번 클릭으로 송출** |
| 제목 슬라이드 | `창 1:1-6` 이 먼저 나간다 | **나가지 않는다** (바로 본문) |
| 되돌리기 | 없음 | **`↩ 직전으로`** 로 설교 화면 복귀 |
| 쓸 때 | 본문 낭독 | 설교 중 인용 |

목록 줄은 이렇게 보입니다.

```
▾ 말씀
  📋 설교 — 홍길동 목사
  💬 창 1:1 태초에 하나님이 천지를 창조하시니라
  💬 창 1:2 땅이 혼돈하고 공허하며 흑암이 깊음 위에 있고 하나님의 영은…
  💬 창 1:3 하나님이 이르시되 빛이 있으라 하시니 빛이 있었고
```

- 절마다 **독립된 항목**이라 `↑ ↓ ✕` 로 하나씩 옮기고 지울 수 있습니다.
  설교 흐름 사이사이에 끼워 넣으라고 낱개로 만든 것입니다.
- **역본**은 성경과 같은 방식으로 고릅니다 (주 역본 + 보조 최대 2).
  나중에 항목에서 역본을 바꾸면 목록 줄의 본문도 새 역본으로 다시 읽습니다.
- 저장 구조가 **성경 항목과 같습니다.** 그래서 참조 표기·절 번호·글꼴·템플릿을
  성경과 똑같이 항목마다 정할 수 있고, **본문은 언제나 DB 에서 읽습니다**
  (목록에 보이는 글자는 라벨일 뿐입니다).

#### 네 화면이 모두 같은 글로 나옵니다 ★

인용구는 **참조를 본문 앞에 붙여** 내보냅니다.

```
고전 1:3 하나님 우리 아버지와 주 예수 그리스도로부터 은혜와 평강이 있기를 원하노라
```

| 화면 | 나오는 것 |
|---|---|
| 관리자 목록 | `고전 1:3 하나님 우리 아버지와…` |
| OBS 송출 | `고전 1:3 하나님 우리 아버지와…` |
| 강사 모니터 | `고전 1:3 하나님 우리 아버지와…` |
| 프로젝터 | `고전 1:3 하나님 우리 아버지와…` |

- **절 번호는 붙지 않습니다** — `고전 1:3` 에 이미 절이 들어 있습니다
- **참조 줄이 따로 나오지 않습니다** — 같은 것이 두 번 나가면 안 되니까요
- 참조를 빼고 본문만 띄우려면 항목의 **참조 표기**를 `끔` 으로 두세요

> 이렇게 한 이유: 네 화면은 서로 다른 렌더러를 씁니다. 참조를 별개 요소로 두면
> 화면마다 위/아래/없음이 갈려 **같은 절이 네 가지로** 보였습니다. 글자에 넣으면
> 네 화면이 그것을 '본문' 으로 받으므로 어긋날 자리가 없어집니다.

**📖 성경(본문 낭독)은 조금도 바뀌지 않습니다** — 절 번호가 붙고, 참조 줄이 따로
나오고, 보조 역본도 그대로입니다.

#### 설교 중에 쓰는 흐름

1. 설교 제목(📋)을 띄운 상태로 설교가 진행됩니다
2. 인용할 차례에 💬 줄을 **한 번 클릭** → 그 절이 바로 나갑니다
3. **`↩ 직전으로`** 를 누르면 설교 제목 화면으로 돌아옵니다

> 옛 순서표에 남아 있는 **자유 글자 인용구**는 그대로 광고처럼 글자가 나갑니다.
> 새로 만들 수는 없습니다 — 자유 글자는 📝 광고를 쓰세요.

### 1.4.1 교독문·주기도문·사도신경 꾸미기

이 셋은 항목을 고르면 상세 칸에 표시 설정이 나옵니다.

| 설정 | 내용 |
|---|---|
| 판본 | 주기도문·사도신경만. 개역개정 / 개역한글 |
| 배경 | `~/Desktop/Data/Background` 의 그림 목록에서 고른다 (템플릿 배경을 이 항목에서만 덮는다) |
| 폰트 | **고딕 / 명조** |
| 글자 크기 | 템플릿 크기에 곱하는 배수. **줄 간격은 그대로 유지됩니다** |
| 화면 넘김 | 전례문만. 2줄 · 4줄 · 6줄 · 전체 한 장 |
| 본문 고치기 | 교회 판본이 내장본과 다를 때. 고치면 **이 항목에만** 적용된다 |

**글자 크기를 올려도 줄 간격이 벌어지지 않습니다.** 줄 간격을 글자 크기의 배수가 아니라
**절대값으로 고정**했기 때문입니다. 크기를 키울 때 긴 줄이 두 줄로 감기면 미리 경고가 뜹니다.

> **1920×1080 기준입니다.** OBS 브라우저 소스를 1920×1080 으로 두세요. 그보다 작으면
> 자동 축소가 개입해 크기를 올려도 잘 커지지 않습니다.

고친 내용은 **단독 송출 중이면 곧바로 화면에 반영**됩니다. 순서표 전체를 올린 상태라면
`예배용으로 올리기` 를 다시 눌러야 합니다 (그 안내가 항목 칸에 표시됩니다).

### 1.4.2 찬양 표시 언어

찬양 항목을 고르면 **표시 언어 (최대 3)** 가 나옵니다.

- **누른 순서가 화면 위아래 순서**입니다. `위 한국어 · 아래 English` 로 표시됩니다
- 곡에 그 언어 가사가 없으면 버튼에 `·` 가 붙습니다
- 매주 고르지 않으려면 **기본 설정 → 찬양 표시 언어**로 기본값을 정해 두세요
  (앞으로 넣는 항목에 채워집니다)
- 템플릿은 **하단 — 성경·찬송 겸용**을 쓰면 주/보조 줄이 크기로 구분됩니다

### 1.4.3 성경·찬양 항목 꾸미기

항목을 고르면 상세 칸에 나옵니다.

| 설정 | 성경 | 찬양 |
|---|---|---|
| **폰트** | 고딕 / 명조 | 고딕 / 명조 |
| **참조 표기** (`요 3:16`) | 템플릿 따름 · 켬 · 끔 | — |
| **소제목** | 템플릿 따름 · 켬 · 끔 | — |
| **절 번호** | 템플릿 따름 · 켬 · 끔 | 템플릿 따름 · 켬 · 끔 |
| 화면 넘김 | 1절씩 · 자동 · 2절씩 · 구간 전체 | 1·2·4줄씩 · 섹션 전체 |

**세 갈래인 이유**: `템플릿 따름`과 `끔`은 다릅니다. '따름'은 템플릿을 바꾸면 함께
바뀌고, '끔'은 이 항목에서만 끈 것입니다. `템플릿 따름`을 고르면 **지금 무엇이 나가는지**
옆에 적어 줍니다 (`지금 켜져 있음 (위)`).

> **찬양에는 참조 표기·소제목이 없습니다.** 화면 구조에 그 자리가 없어서 절 번호만
> 고를 수 있습니다.

> **폰트는 한국어 줄에만 적용됩니다.** 영어·헬라어·히브리어는 그 언어 전용 글꼴을
> 그대로 씁니다 — 라틴 문자에 한글 명조를 씌우면 글자가 어색해집니다.

**크기·색·테두리·줄 간격은 템플릿 탭**에서 정합니다. 여기서 정하는 것은
**폰트와 켜고 끄기**뿐입니다.

### 1.5 순서 표시 꾸미기

`좌우` 배치에서는 **왼쪽에 순서 이름, 오른쪽에 담당자 + 밑줄** 로 나갑니다.
담당자 줄이 없으면 오른쪽 칸과 밑줄을 만들지 않습니다.

항목을 고르면 아래에서 조정합니다. **지정하지 않으면 템플릿 값**을 씁니다.

| 조정 | 내용 |
|---|---|
| 배치 | `좌우`(기본) / `쌓기` |
| 담당자 크기 | 템플릿 보조 크기에 대한 배수 (기본 80%) |
| 테두리 | 순서·담당자 외곽선 두께(px). `0` 이면 그 항목만 끈다. `↺` 로 템플릿 값 복귀 |
| 글자 조정 | 글자마다 크기·높낮이를 직접. `↺` 하나만 / `전부 자동으로` |

**단독 송출 중이면 슬라이더를 움직이는 즉시 화면이 따라옵니다.**
순서표 전체를 올린 뒤에는 반영되지 않습니다 — **예배용으로 올리기** 를 다시 누르세요.

#### 글자 리듬 (자동)

어절의 **첫 글자부터 네 글자까지** 아래를 따릅니다. 띄어쓰기를 만나면 다시 시작합니다.

| 순서 | 크기 | 높낮이 |
|---|---:|---:|
| 첫째 | 100% | 0 |
| 둘째 | 96% | ↑19% |
| 셋째 | 90% | ↓10% |
| 넷째 | 90% | ↑5% |

`예배부름`(4자)이 기준이고 `축도`(2자)·`축복송`(3자)은 앞부분을 그대로 따릅니다.
**다섯째 글자부터는 자동이 손대지 않습니다** — `찬양과경배` 같은 이름은 글자 조정으로 직접 맞춥니다.

세기는 **템플릿** 탭 → 표시 옵션의 `글자 리듬`·`글자 높낮이` 로 조절합니다(100% = 위 표 그대로).

### 1.6 예배 전 안내 (자동 진행)

구분을 하나 만들고 그 아래에 안내 항목을 담은 뒤, 구분을 골라 **예배 전 안내** 를 켭니다.

- 기본 **8초** 마다 넘어가고 마지막에서 **처음으로 돌아간다**
- 저절로 시작되지 않는다 — 그 구분의 **▶** 를 눌러야 시작
- **다른 항목을 송출하거나 '예배용으로 올리기' 를 누르면 즉시 멈춘다**
- 도는 동안 노란 띠와 **■ 정지** 가 계속 보인다

예배 순서 자체(예배 중 덱)는 마지막에서 순환하지 않습니다. 순환은 **예배 전** 구간뿐입니다.

### 1.6.5 프로젝터로 띄우기 ★

TV 가 아니라 **프로젝터**로 띄울 때 씁니다. 프로젝터는 대비가 낮아 글씨가 뭉개지므로
이 창은 **크고 두껍게** 그립니다.

컨트롤 패널 오른쪽 위의 **프로젝터** 버튼을 누르면 새 창이 뜹니다.

| 순서 | 할 일 |
|---|---|
| ① | **프로젝터** 버튼을 누른다 |
| ② | 그 창을 프로젝터로 나가는 화면으로 **드래그**한다 |
| ③ | **화면을 한 번 클릭한다** → 주소줄·제목줄까지 사라진 전체 화면이 된다 |

`F` 를 눌러도 같습니다. **다음에 열 때는 첫 클릭이나 첫 키 입력에서 저절로 전체 화면이
됩니다** — 전체 화면으로 쓰고 있었다는 것을 기억합니다. 창으로 돌아가려면 `Esc` 나
막대의 **전체 화면 해제** 를 누르세요(그러면 다음에도 창으로 열립니다).

> **주소줄·제목줄을 없애는 방법은 두 가지뿐입니다.** 웹페이지가 브라우저의 주소줄을
> 지우는 방법은 없습니다 — 있다면 피싱 페이지가 은행 주소를 위조할 수 있으므로 모든
> 브라우저가 막아 둔 것입니다.
>
> | 방법 | 결과 |
> |---|---|
> | **전체 화면** (클릭 · `F`) | 주소줄·제목줄·탭·창 테두리가 **모두** 사라진다 |
> | **앱으로 설치** (아래) | 애초에 주소줄이 없는 창으로 열린다 |
>
> 전체 화면은 브라우저 규칙상 **사람이 누르는 순간에만** 됩니다. 창이 뜨자마자 저절로는
> 되지 않습니다.

#### 매주 쓰신다면 '앱으로 설치'

설치하면 **처음부터 주소줄이 없는 전체 화면**으로 열립니다. 클릭할 필요도 없습니다.

- **크롬·엣지**: 주소창 오른쪽의 설치 아이콘(⊕) 또는 메뉴 →
  **캐스트·저장 및 공유 → 페이지를 앱으로 설치**
- **사파리 17 이상**: 파일 → **독에 추가**
- **아이패드를 프로젝터에 물릴 때**: 공유 → **홈 화면에 추가**

앱 이름은 **예배 프로젝터** 입니다. 지우려면 크롬 → `chrome://apps` 에서 삭제하세요.
서버(포트 7777)가 꺼져 있으면 빈 화면이 뜨므로, 서버를 먼저 켜세요.

#### 조작 막대는 마우스를 움직일 때만 나옵니다

평소에는 **아무것도 없습니다** — 마우스 커서까지 숨습니다(벽에 커서가 비치지 않게).
마우스를 움직이면 위쪽에 막대가 나오고, 2.5초 동안 가만히 두면 다시 사라집니다.

| 막대 | 키보드 | 동작 |
|---|---|---|
| **− / +** | `−` `+` | 글자 크기 50~250% (`0` 으로 100% 로) |
| **반전** | `I` | 검은 바탕 ↔ 흰 바탕 |
| **전체 화면** | `F` | 주소줄까지 숨긴다 |

글자 크기와 반전은 **저장됩니다.** 창을 다시 열어도 그대로입니다.

#### OBS 와 다른 배치를 동시에 씁니다

이것이 이 화면의 핵심입니다.

| 화면 | 무엇으로 그리나 |
|---|---|
| OBS 송출 | **활성 템플릿** (예: 하단 두 줄 — 카메라 영상 위) |
| 프로젝터 | **'전체 — 성경·찬송 겸용'** 고정 (벽에 크게) |

즉 카메라 영상 위에는 하단 두 줄로 나가면서, 프로젝터에는 같은 내용이 큰 글씨로
나갑니다. 템플릿을 갈아 끼울 필요가 없습니다.

- 템플릿 탭에서 **'전체' 프리셋을 고치면 프로젝터도 따라갑니다** (숨은 설정이 아닙니다)
- 다른 템플릿을 편집하는 중에도 **프로젝터는 흔들리지 않습니다**
- **배경 그림은 나오지 않습니다** — 프로젝터에서 사진 위의 글씨는 읽히지 않습니다
- **순서 표시 제목은 글자 크기가 고릅니다** (첫 글자 크기로 통일). 붓글씨처럼 흔드는
  리듬은 대비가 낮은 프로젝터에서 작아진 글자가 먼저 뭉개집니다. 손으로 맞춘 글자별
  조정도 여기서는 무시합니다 — **OBS 송출은 그대로입니다**
- **회중 줄·영어 가사도 크게** 나갑니다 (교독문 회중 줄은 인도자 줄과 같은 크기)
- 이 창은 **OBS 연결 수에 세지 않습니다** — 'OBS 미연결' 표시는 정상입니다

#### 글자가 화면을 넘칠 때

막대에 **⚠ 글이 화면을 넘칩니다** 가 나옵니다. `−` 로 줄이세요.

이 창은 글이 넘칠 때 저절로 줄이지 **않습니다.** 저절로 줄이면 `+` 로 키운 만큼
되돌려 깎아서 '글자 크기가 안 바뀐다' 가 되기 때문입니다.

## 2. 성경 탭

한 본문을 깊게 다룰 때 씁니다(예배 순서에 넣지 않고 즉석에서 띄울 때).

- 참조 입력은 여러 표기를 받습니다: `요 3:16` `요한복음 3장 16절` `시 23` `창 1-2`
  `마 5:3-12; 6:9-13` `ㅇㅎㅂㅇ 3:16`(초성) `Gen. 1:1`
- 책 이름이 여러 곳에 걸리면 추측하지 않고 **후보 버튼**을 보여 줍니다
- 주 역본 1개 + 보조 역본 최대 2개
- 화면 넘김: `1절씩`(기본) · `자동`(실측해서 넘치기 직전까지) · `2절씩` · `구간 전체`
- **화면·폰트** — 이 탭에서 띄울 때 쓸 프리셋(하단·전체·좌우)과 글꼴을 고릅니다.
  고르지 않으면 `템플릿 그대로` 로, 지금 화면 모양을 그대로 씁니다

> 순서 표시·교독문·전례문 프리셋은 목록에 없습니다 — 그 항목 전용이라 본문에 쓰면
> 크기와 배치가 맞지 않습니다.

## 3. 찬양 탭

- 검색: `305`(모든 곡집) · `새 305` `통 405`(곡집 지정) · `나같은죄인`(공백 무시) · 가사 부분일치
- **Enter = 첫 결과를 열고 곧바로 송출** — 예배 중 곡이 갑자기 바뀌어도 손이 멈추지 않는다
- 검색창이 비면 **즐겨찾기 5곡**이 칩으로 나온다 (☆ 로 지정)
- 슬라이드 목록에 **절 번호**가 `1. ` 형식으로 붙는다 (각 절의 **첫 장에만**)
- 곡집 관리 → **가사 점검** 으로 송출할 수 없는 곡을 찾는다 (아무것도 지우지 않는다)
- **표시 언어 (최대 3)** — 누른 순서가 화면 위아래 순서. 곡에 없는 언어에는 `·` 가 붙는다
- **화면·폰트** — 이 탭에서 띄울 때 쓸 프리셋(하단·전체·좌우)과 글꼴 (성경 탭과 같습니다)

### 3.1 가사 편집 — 언어별 비교 격자

곡을 열고 **가사 편집**을 누르면 줄마다 언어를 모아 놓은 격자가 나옵니다.

```
1절                          한국어 2  English 2  中文 1
──────────────────────────────────────────────────────
1  한국어  나 같은 죄인 살리신
   English Amazing grace! how sweet the sound
   中文    奇異恩典 何等甘甜
──────────────────────────────────────────────────────
2  한국어  주 은혜 놀라워
   English That saved a wretch like me!
   中文    ⚠ 이 줄에 가사가 없습니다 — 눌러서 넣기
```

- **아무 줄이나 눌러서 그 자리에서 고칩니다.** `Enter` 저장 · `Esc` 취소
- 절 머리의 **언어별 줄 수**로 어긋남을 먼저 봅니다. 수가 안 맞는 언어는 노랗게
- 짝이 없는 자리는 **빈칸으로 두지 않고** '눌러서 넣기' 로 보여 줍니다
- **편집할 언어**를 켜면 아직 없는 언어도 넣을 자리가 생깁니다 (`+` 표시)
- 언어를 잘못 넣었으면 격자 아래 **`… 가사 전체 지우기`**

> **왜 언어를 옆으로 늘어놓지 않는가**: 랩탑에서 편집 칸 폭이 479px 인데 3개 언어를
> 나란히 놓으면 865px 이 필요합니다(영어 한 줄이 458px). 좌우로 계속 밀어야 해서
> 줄로 묶고 언어를 위아래로 놓았습니다.

### 3.2 타언어 가사 — 한국어를 옆에 두고 적기

**＋ 타언어 가사 추가** 를 누르고 언어를 고르면 창이 열립니다.

```
한국어 (기준)              English — 같은 줄 수로 적으세요
─────────────────────    ─────────────────────────────────
[1절]                     [1절]
나 같은 죄인 살리신          Amazing grace how sweet the sound
주 은혜 놀라워              That saved a wretch like me
```

**왼쪽 한국어를 보면서 오른쪽에 적으면 그때그때 짝지어집니다** — 버튼을 누를 필요가
없습니다. 위쪽 격자에 `|` 형식으로 바로 들어갑니다.

- 창 제목 옆에 **절마다 줄 수**가 보입니다 — `1절 4/4 · 2절 0/4` 처럼, 어느 절이
  비었는지 **적는 동안** 알 수 있습니다. 다 맞으면 `모두 줄 수가 맞습니다`
- 절 사이는 **빈 줄**로 나눕니다. `[2절]` 라벨을 붙이면 그 절에 들어갑니다
- **한국어와 다른 언어는 건드리지 않습니다**
- 창을 **비우면** 그 언어만 걷힙니다 (다른 언어는 남습니다)
- 확인하고 **가사 저장**을 눌러야 저장됩니다

> **고를 수 있는 언어는 한국어·English 입니다** (2026-08-23). 中文·日本語 는 넣은 가사가
> 0줄이어서 화면에서 뺐습니다 — 고를 것이 많으면 정작 쓰는 한/영이 묻힙니다.
> 데이터는 그대로 읽으므로, 그 언어 가사가 있는 곡에서는 계속 보입니다.
> 다시 켜려면 `lib/lang-select.ts` 의 `ACTIVE_LANGS` 에 한 줄을 더하면 됩니다.

악보에서 옮길 때 **음절 하이픈을 떼세요** — `bless-ings` 는 화면에서 오타로 보입니다.

> 영문 가사 출처와 저작권 경계는 [plan-bilingual-songs.md](plan-bilingual-songs.md) 를 보세요.
> 공공 영역 찬송가는 Hymnary.org, 현대 CCM 은 CCLI SongSelect 입니다.

### 3.4 여러 곡을 한 번에 — 폴더로 반입

곡이 수십 개면 화면에서 하나씩 붙여 넣는 대신 파일로 넣습니다.

```
~/Desktop/Data/Lyrics/
  en/hymn_new/305.txt      ← 언어 / 곡집 / 번호.txt
  en/hymn_new/1.txt
  zh/hymn_old/405.txt
```

```bash
npm run lyrics:lang -- --dir ~/Desktop/Data/Lyrics
```

**미리보기가 기본입니다.** 무엇이 들어갈지 보고 `--apply` 를 붙입니다.

- 파일 이름이 **번호**인 이유: 번역판 제목은 원곡과 달라 기준이 될 수 없습니다
  (`Amazing Grace` = `나 같은 죄인 살리신`). `(곡집, 번호)` 가 고정 좌표입니다
- **한국어(`ko`)는 받지 않습니다** — 승인한 가사를 파일로 덮어쓰지 않기 위해서입니다
- 같은 번호의 곡이 둘이면 **멈추고 알려 줍니다** (실제로 35건 있습니다)
- 줄 수가 어긋난 곡은 **어느 절 몇 줄인지** 먼저 보여 줍니다
- 넣기 전에 스냅샷을 뜹니다

한 언어·한 곡집만 하려면 `--lang en` `--book hymn_new` 를 붙입니다.

### 3.3 원문으로 편집 (대량 붙여 넣기)

접힌 칸에 텍스트 원문이 있습니다. `[1절]` 로 섹션을 나누고, `|` 로 시작하는 줄은
직전 줄의 번역입니다.

```
[1절]
나 같은 죄인 살리신
| Amazing grace! how sweet the sound      ← 표가 없으면 영어
|zh 奇異恩典 何等甘甜                      ← |zh |ja 로 언어를 지정
```

## 4. 검토 탭

자동 줄나눔은 **제안**이고, 여기서 승인해야 확정됩니다.

| 키 | 동작 |
|---|---|
| `Enter` | 승인 + 다음 곡 |
| `↑` `↓` (`k` `j`) | 이동 |
| `P` | 이 곡을 실제로 송출해 본다 (**예배 중 금지**) |

승인한 곡은 `lines_source = manual` 이 되어 **이후 어떤 자동 작업도 건드리지 않습니다.**

## 5. 템플릿 탭

값을 만지면 송출 화면에 **즉시** 반영되고(저장 전), 버튼을 눌러야 남습니다.

| 프리셋 | 쓰임 |
|---|---|
| **하단 — 성경·찬송 겸용** | 가장 많이 쓰는 배치 |
| **전체 — 성경·찬송 겸용** | 화면을 채우는 큰 글씨 |
| **좌우 — 성경·찬송 겸용** | 두 벌을 나란히 (원어 대조·한영 찬양) |
| 순서 표시 — 명조 리듬 | 순서 표시 |
| 교독문 — 인도자/회중 | 교독문 |
| 주기도문·사도신경 — 전체화면 | 전례문 |
| 로우서드 | 설교자·광고 |
| 공백 | 블랭크 |

> **'단일 역본'·'이중 역본' 이 없어진 이유**: 아무것도 가르지 않았습니다. 역본이나
> 언어를 둘 고르면 둘째 줄이 그냥 나옵니다 — 역할은 **내용**이 정하고 템플릿은
> **모양만** 정합니다. 그래서 넷을 '하단' 하나로 합쳤습니다.

### 5.0 버튼 다섯 개 ★

| 버튼 | 하는 일 |
|---|---|
| **프리셋 덮어쓰기** | 지금 값을 그 프리셋 자리에 저장합니다 |
| **사본 만들기** | 따로 하나 더 만듭니다 |
| 편집 취소 | 저장 전 값으로 되돌립니다 |
| **원본 불러오기** | 프로그램에 적힌 **원래 값**으로 되돌립니다 |
| 프리셋 백업 / 불러오기 | 템플릿만 담은 JSON 파일로 옮깁니다 |

**프리셋을 고쳐도 원본은 사라지지 않습니다.** 원본이 프로그램 코드에 있어서, 언제든
`원본 불러오기`로 되돌아옵니다. 고친 프리셋은 목록에 `[프리셋·고침]` 으로 표시되고
**자리도 그대로** 지킵니다.

> 백업·불러오기는 **템플릿만** 담습니다. 곡·순서표까지 옮기려면 설정 탭의
> **데이터 이전**을 쓰세요.

### 5.1 배경 (카메라 없이 쓸 때)

배경 → `그림` / `반복 동영상`. 파일은 두 방법 다 됩니다.

- `data/backgrounds/` 폴더에 직접 넣고 **새로 고침**
- 템플릿 탭에서 **올리기** (한 파일 64MB 까지)

맞춤(채우기/전체 보이기)과 불투명도를 조절합니다. 파일이 없거나 못 읽어도
**화면을 비우지 않고** 배경만 빠집니다. **배경 파일은 데이터 이전(백업)에 담기지 않습니다.**

### 5.2 폰트 — '실제 사용' 표시를 꼭 보세요

**대표 폰트는 `Noto Sans KR`(고딕)·`Noto Serif KR`(명조)입니다.** 한 집안이라 섞어 써도
글자 폭·높이가 어울리고, 맥·윈도우에 모두 설치할 수 있어 교회 PC 를 바꿔도 같은 화면이
나옵니다. **설정 탭 → 화면 폰트**에서 깔려 있는지 확인하고 없으면 거기서 받으세요.

> 폰트가 없어도 **화면은 멀쩡해 보입니다.** 브라우저가 조용히 다른 글꼴로 바꾸기 때문에
> '명조를 골랐는데 고딕이 나온다' 를 예배 중에야 알게 됩니다. 그래서 설정 탭이 묻지 않고
> 재서 알려 줍니다.

폰트 이름은 적어 넣은 대로 잡히지 않는 일이 잦습니다. 그래서 폰트 칸 아래에
**실제로 쓰이는 폰트**를 표시합니다.

> 실제 사용: **Noto Serif KR** · 없는 폰트: …

총칭(`serif`)까지 떨어지면 빨간 글씨로 알립니다 — 글자마다 다른 폰트로 대체돼
자간이 깨질 수 있다는 뜻입니다.

## 6. 설정 탭

- 서버 주소·OBS URL·데이터 폴더 확인
- **화면 폰트** — 권하는 폰트 두 개가 깔려 있는지 **재서** 알려 준다 (5.2 참고)
- **데이터 이전** — 찬양·템플릿·예배 순서·설정·폰트를 JSON 한 파일로 내보내기/가져오기
  (성경 DB 와 배경 파일은 담기지 않는다. 가져오기는 **추가**가 기본)

## 6.1 강사 모니터 (예배당 뒷벽 화면)

오른쪽 위 **강사 모니터** 버튼을 누르면 창이 하나 열립니다. 이 창을 강단 모니터에
전체화면으로 두세요.

| | 어디로 | 무엇 |
|---|---|---|
| 강단(회중) | **OBS 브라우저 소스** | 본문·가사. 카메라·배경과 합성 |
| 강사·찬양팀 | **이 창** (OBS 를 거치지 않는다) | 지금 화면 · 다음 · 이후 · 진행 · 현재 시각 |

- **글자 크기**를 `+` `-` 로 조절, `0` 으로 되돌립니다 (60~260%, 기억됩니다).
  뒷벽에 붙여 멀리서 보는 화면이라 크게 키울 수 있습니다
- 교독문처럼 두 줄이 나오면 **흰색 / 노란색**으로 누가 읽을 차례인지 구분합니다
- **블랙을 켜면 경고가 뜹니다** — 강사가 화면이 나가는 중인지 알 수 있어야 합니다
- 연결이 끊겨도 **마지막 화면을 그대로 둡니다**

## 7. 출력 화면(OBS)에서 무엇이 어떻게 나오는가

| 항목 | 화면 |
|---|---|
| 성경 | 역본 블록을 위아래(또는 좌우)로. 절 번호는 템플릿 옵션 |
| 찬양 | 가사 줄. **각 절 첫 장에만** `1. ` 이 붙는다(번역 줄에는 안 붙음) |
| 순서 표시 | 좌우 배치 + 밑줄, 글자마다 리듬 |
| 광고 | 줄 그대로 |
| 공백 | 글자를 지운다 (배경은 템플릿 소관이라 남는다) |
| 블랙(`B`) | 내용을 **남긴 채** 숨긴다. 사람이 끌 때까지 유지된다 |

**화면은 스스로 비워지지 않습니다.** 서버가 죽어도 마지막 내용을 유지하고 재연결만 시도합니다.

## 태블릿·다른 기기로 조작하기

기본은 **이 PC 안에서만** 열립니다. 다른 기기로 조작하려면 그때만 엽니다.

```bash
npm run start:lan
```

기동하면 접속 주소가 나옵니다.

```
태블릿 접속      : http://192.168.1.190:7777/
LAN 에 열려 있습니다 — 이 앱은 인증이 없어 같은 WiFi 의 누구나 조작할 수 있습니다
예배가 끝나면 닫으세요 (그냥 npm start 로 실행하면 이 PC 안에서만 열립니다)
```

⚠️ **인증이 없습니다.** 열려 있는 동안에는 같은 WiFi 의 누구나 컨트롤 패널을 열어
예배 중 화면을 바꾸거나 찬양 가사를 지울 수 있습니다. 게스트 WiFi 가 같은 망이면
특히 위험합니다. 필요할 때만 열고 끝나면 `npm start` 로 돌아가세요.

**태블릿에서 접속이 안 될 때**

| 확인 | 방법 |
|---|---|
| LAN 모드로 떴는가 | 기동 로그에 `태블릿 접속` 주소가 보이는지 |
| 같은 WiFi 인가 | 맥과 태블릿이 같은 공유기에 붙어 있는지 |
| 주소가 맞는가 | 기동 로그의 주소를 그대로 입력 (자동으로 바뀔 수 있음) |
