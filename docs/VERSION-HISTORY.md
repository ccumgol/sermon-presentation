# 판 이력 (Version History)

받는 사람이 **"내 것이 어느 판이고 무엇이 달라졌나"** 를 한 자리에서 보는 문서입니다.
자세한 판단 근거와 검증 방법은 [work-log](work-log.md) · [CHANGELOG](CHANGELOG.md) 에 있습니다.

---

## 판 번호를 붙이는 규칙 (2026-09-12, 사용자 결정)

| 무엇 | 어떻게 | 보기 |
|---|---|---|
| 간단한 고침 | **가운데 자리**를 올린다 | `1.0` → `1.1` → `1.2` |
| 중요한 변경 | **앞자리**를 올리고 나머지는 0 | `1.9` → `2.0` |

**커밋할 때마다 올립니다.** `package.json` 의 `version` 이 곧 판 번호이고,
설치 파일 이름(`SermonPresentation-1.0.0-arm64.dmg`)과 설정 탭의 **서버 정보 → 판**
에 그대로 나옵니다.

> `package.json` 은 세 자리(semver)를 요구해서 `1.0` 은 **`1.0.0`** 으로 적습니다.
> 읽을 때는 앞 두 자리만 보면 됩니다 — 마지막 자리는 늘 `0` 입니다.

**Agent 에게**: 코드를 고쳐 커밋할 때 이 문서에 한 줄을 더하고 `package.json` 의
판을 함께 올립니다. 문서만 고친 커밋은 올리지 않습니다 — 프로그램이 그대로이기 때문입니다.

## 1.0.0 — 2026-09-12

**첫 정식 판.** 그전까지는 `0.1.0` 하나로 여러 번 다시 만들어서, 받는 사람이
어느 것을 쓰는지 **파일 이름으로는 알 수 없었습니다.**

이번 판에 들어간 것 (설치판 기준 2026-09-10 판 이후):

### 새 기능

- **카메라 영상 위에서 글자가 읽히게 하는 배경 레이어 둘**
  - *화면 전체* — 템플릿 탭 → 배경 → `단색·반투명 띠` + **투명도 슬라이더**.
    엔진은 전부터 있었지만 화면에 조절 칸이 없어 0.5 로 굳어 있었습니다
  - *글자 영역만* — 템플릿 탭 → 위치 → **`글자 영역 뒤에 네모 깔기`**.
    소제목·본문·참조를 **한 네모**가 감쌉니다 (글자 카드의 '글자 뒤 상자' 는
    줄마다 그려져 끝이 들쭉날쭉합니다)
- **항목 설정 칸의 높이를 끌어서 조절** — 예배 순서 탭에서 목록과 설정 칸 사이를
  끕니다. 슬라이더가 많은 항목('순서 표시' 등)의 아래쪽 설정이 잘려 보이던 것을 풉니다.
  더블클릭이나 `Home` 으로 기본값

### 고친 것

- **내 배경 폴더에서 고른 그림이 안 뜨던 것** — 템플릿이 *어느 폴더*에서 왔는지를
  담지 않아 늘 `data/backgrounds/` 에서 찾다가 404 가 났습니다.
  `~/Desktop/Data/Background` 의 그림은 **여태 한 번도 뜬 적이 없었습니다**
- **판이 섞여도 배경이 살아난다** — 폴더 정보 없이 온 그림이면 출력 화면이
  다른 폴더를 한 번 더 찾아봅니다. 옛 조작 화면·옛 설치판과 함께 써도 배경이 뜹니다
- **색상자로 색을 고르면 투명도가 사라지던 것** — 이제 색만 바뀌고 진하기는 남습니다
- **설정 탭 '이 PC 준비 상태' 가 윈도우에서 6초 걸리던 것** → 3초
  (설치 도구를 하나씩 찾다가 함께 찾도록)

### 설치 편의

- **맥 DMG 에 두 파일이 함께 들어갑니다** — `맥에서 처음 열기.command`(격리 표시를
  지우고 앱을 엽니다) · `먼저 읽어보세요.txt`(붙여넣을 수 있는 안내)
- **윈도우 설치 중에 OBS·Chrome 을 함께 설치**할 수 있습니다 (winget).
  실패해도 앱 설치는 그대로 끝나고, 앱의 '이 PC 준비 상태' 에서 다시 할 수 있습니다

### 아래에서 도는 것

- 밀 때마다 **CI 가 검사**합니다 (`tsc` · `vitest` · 빌드, Node 24·26 둘 다)
- 죽은 코드를 막는 설정 (`noUnusedLocals` · `noUnusedParameters`)
- 검사 **2,074개**
