CONTROL PANEL

탭 6개 — 어디서 무엇을 하나

  • 예배 순서 — 순서를 짜고 진행한다. 가장 많이 쓰는 한 열
  • 성경 — 참조로 본문을 찾아 미리 확인한다 (역본 12종)
  • 찬양 — 곡·가사·언어를 관리한다. 곡집 반입
  • 검토 — 가사가 의심스러운 곡을 사람이 승인한다
  • 템플릿 — 배치·글자·배경 프리셋을 고친다
  • 설정 — OBS 주소, 폰트 설치, 데이터 이전, 프로젝터 안내

OUTPUT
