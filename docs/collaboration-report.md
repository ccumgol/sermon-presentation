### 4.4 보안 (SECURITY-AUDIT 기준)

감사: [SECURITY-AUDIT.md](SECURITY-AUDIT.md) (2026-08-16, Agent J).
조치 순서는 Agent C 가 검증하며 한 가지를 바꿨다 — **H-2 자동 백업을 H-3 보다 앞으로.**
Origin 검사는 화면이 바뀌는 피해지만, `replace` 는 **되돌릴 수 없는 데이터 손실**이다.

| 순서 | ID | 항목 | 상태 | 담당 |
|---|---|---|---|---|
| 1 | **H-1** | 기본 바인딩을 `127.0.0.1` 로, 태블릿은 환경변수로 열기 | 🟢 완료 | Agent C (2026-08-16) |
| 2 | **H-2** | `replace` 가져오기 직전 서버가 자동 백업 | 🟢 완료 | Agent C (2026-08-16) |
| 3 | **H-3** | WebSocket Origin 검사 (Origin 이 있을 때만) | 🟢 완료 | Agent C (2026-08-16) |
| 4 | **S-1** | 배경 삭제 API + 총량 상한 | ⛔ **기능 자체를 덜어내 소멸** | Agent C (2026-08-18) |
| 5 | 권고 5 | 접속 암호 | ⚪ **보류 (조건부)** | 랜을 열 때 |
| 6 | M-2·L-2 | 요청 수 제한 | ⚪ **보류 (조건부)** | 랜을 열 때 |

**5·6번을 왜 보류했나** (2026-08-16, 사용자 결정)

둘 다 **랜을 열 때만** 의미가 있다. 지금은 `127.0.0.1` 고정(H-1)이라 같은 PC 에서만 닿는다.
"태블릿으로 조작할 계획이 있는가"를 확인했고, **당장은 없다**는 답을 받았다.

태블릿의 이점을 따져 보니 — 설교자가 강대상에서 직접 절을 넘기는 것 하나만 태블릿이어야
가능하고, 나머지(실제 투사면을 보며 조작)는 두 번째 모니터로 대체된다. 반면 비용은
**키보드 단축키 상실**(`PlanPanel`·`ReviewPanel` 의 `↓↑`/`j k`/`Enter`/`Tab` — 예배 중
안 보고 누르던 것을 화면을 봐야 누르게 된다), **예배 중 와이파이 끊김**, 교회 공용망 노출이다.

**되살리는 조건** — 셋 중 하나라도 생기면 5·6번을 먼저 하고 랜을 연다:
1. 설교자가 본인이 넘기고 싶어 하신다
2. 조작자가 두 명 이상이 된다
3. 조작석이 OBS PC 에서 물리적으로 떨어진다

그때 필요한 것은 **접속 암호 + 요청 수 제한 + 터치용 큰 버튼**, 반나절~하루. 미리 해두지
않는다 — 안 쓰는 기능에 붙은 암호는 잊어버리기만 한다. 참고로 컨트롤 패널은 900px 미만에서
2단이 1단으로 접히므로(`styles.css`), 태블릿을 쓴다면 **가로**여야 한다.

## 8.1 중단된 작업을 이어받는 절차

### 판정 — 추측하지 말고 실제 상태를 본다
`🟡 진행중` 인데 담당자가 응답 없거나 오래됐다고 판단되면 **아래 근거로 직접 확인**하세요.
추측하지 말고 실제 상태를 보고 판단합니다.

```bash
# 1) 미커밋 변경 = 진행 중이던 흔적 (무엇을 만지고 있었는지)
git status --short
git diff                     # 어디까지 고쳤는지

# 2) 파일 수정 시각 = 마지막 활동 시점 (중단 시각 추정)
ls -lt lib/*.ts server/**/*.ts src/control/**/*.tsx scripts/*.ts docs/*.md | head

# 3) 남은 잔여물 확인
git stash list               # 중단 전 stash 했을 수 있음
git branch --no-merged main  # 미병합 작업 브랜치

# 4) 코드가 실제로 동작하는 상태인지 (반쯤 고친 상태일 수 있음)
npx tsc --noEmit
npx vitest run
```

**판정 기준 (제안)**
| 상황 | 판정 | 조치 |
|---|---|---|
| 미커밋 변경 있음 + 파일 수정이 **수 시간 이상 전** | 중단됨 | 8장 로그를 읽고 이어받기. 상태를 `🟡 진행중(인계: 본인)` 으로 갱신 |
| 미커밋 변경 없음 + 보드만 `🟡` | **착수 직후 중단** | 그 항목은 사실상 미착수 → `🔴` 로 되돌리고 새로 시작 |
| 테스트/타입검사 실패 | **반쯤 고친 상태** | 먼저 그 부분을 완성하거나 되돌린 뒤 진행 (사용자에게 보고) |
| 판단이 애매함 | — | **사용자에게 확인** (임의로 되돌리지 말 것) |
