# '예배 순서' 탭 3차 — 한 열 · 펼치기 · 슬라이드 템플릿 (제안)

> **상태**: 제안 · 결정 대기 · 작성 2026-08-15 · Agent J (Opus 5)
> 관련: [plan-service-tab.md](plan-service-tab.md) (1차) · [plan-service-tab-2.md](plan-service-tab-2.md) (2차)

사용자 요청:
1. 2열을 없애고 **한 열**로. 광고·순서 표시는 **한 번에** 송출되게
2. 성경·찬양은 **제목만** 보이다가 클릭이나 `→` 로 **펼쳐서** 슬라이드를 고르게
3. 각 줄에 **쓰이는 템플릿**을 보여 주고, 원하면 바꿔 **저장**

---

## 1. 지금 왜 두 번 눌러야 하는가

1차 재설계에서 **"선택과 송출을 분리"** 를 핵심 결정으로 삼았습니다
([plan-service-tab.md](plan-service-tab.md) §3).

> 항목 클릭 → **선택만**. 화면은 그대로. / 슬라이드 클릭 → **송출**.

이유는 "눌렀다고 바로 나가면 예배 중 사고가 난다" 였습니다. 그래서 왼쪽에서 항목을 고르고
오른쪽에서 슬라이드를 눌러야 나갑니다. **성경·찬양처럼 여러 장인 항목에는 이 구조가 맞지만,
광고·순서 표시·공백처럼 한 장뿐인 항목에는 헛걸음이 됩니다** — 고를 슬라이드가 하나뿐인데
두 번 눌러야 하니까요.

## 2. 제안하는 규칙 — "나가는 것은 언제나 슬라이드"

분리 원칙을 **버리지 않고** 헛걸음만 없앨 수 있습니다.

| 무엇을 누르나 | 동작 |
|---|---|
| **슬라이드 줄** | **송출** (지금도 그렇습니다) |
| 항목 머리 줄 (성경·찬양처럼 **여러 장**) | **펼치기/접기**. 화면은 그대로 |
| 항목 줄 (광고·순서 표시·공백처럼 **한 장**) | 그 줄이 곧 슬라이드이므로 **송출** |
| 구분(그룹 머리글) | 아무것도 나가지 않음 (지금과 같음) |

즉 **"항목을 눌러도 안 나간다"가 아니라 "슬라이드를 눌러야 나간다"** 로 규칙을 다듬습니다.
한 장짜리 항목은 항목과 슬라이드가 같은 것이므로, 한 번 클릭이 규칙에 어긋나지 않습니다.

> ⚠️ 그래도 **동작이 바뀝니다.** 지금은 광고를 눌러도 화면이 안 나가지만, 바뀌면 나갑니다.
> 예배 중 목록을 훑다가 잘못 누르면 그대로 송출됩니다. 아래 ①에서 확인이 필요합니다.

## 3. 화면 구조

```
┌── .main (한 열) ─────────────────────────────┬── .side ────┐
│ [예배 유형 ▾][＋]                            │ 라이브       │
│ [예배용으로 올리기]                          │ 미리보기     │
│ [템플릿 업데이트][순서 저장][순서 불러오기]  │             │
│──────────────────────────────────────────────│ ◀ 이전 다음 ▶│
│ ▾ 예배 부름                        ⏱         │ 블랙 복구    │
│   📋 예배 부름            [설교본문 ▾]  ▶    │             │
│   📋 대표기도             [설교본문 ▾]  ▶    │             │
│ ▾ 찬양                                       │             │
│ ▸ 🎵 새305 나 같은 죄인   [찬양 2언어 ▾] 7장 │  ← 접힘     │
│ ▾ 📖 요 3:16-17           [설교본문 ▾]  2장  │  ← 펼침     │
│     1  하나님이 세상을…              ●       │  ← 송출 중  │
│     2  이는 그를 믿는 자마다…                │             │
│ ▾ 광고                                       │             │
│   📝 성찬식 안내          [광고 ▾]      ▶    │             │
│──────────────────────────────────────────────│             │
│ [📖][🎵][📋][📝][💬][⬛][▾]  [입력…]         │             │
└──────────────────────────────────────────────┴─────────────┘
```

- 오른쪽 열(항목 내용)을 없애고 그 내용을 **펼침 줄**로 목록 안에 넣습니다.
- 펼침은 **한 번에 하나만** 열어 둡니다(아코디언). 여러 개가 열려 있으면 목록이 길어져
  "10항목이 한 화면에" 라는 1차 목표가 깨집니다.
- 항목별 설정(언어·화면 넘김·배치)은 펼친 줄 아래 **설정 줄** 하나로 붙입니다.

## 4. 키보드

| 키 | 목록에서 |
|---|---|
| `↑` `↓` | 줄 이동 (펼쳐진 슬라이드도 한 줄로 셉니다) |
| `→` | 접혀 있으면 **펼치기** · 이미 펼쳤으면 첫 슬라이드로 |
| `←` | **접기** (슬라이드에 있으면 그 항목 머리로) |
| `Enter` | 지금 줄 **송출** |
| `Space` | 송출 중인 덱의 **다음 슬라이드** (지금과 같음) |
| `PgDn` `PgUp` | 항목 단위 점프 (지금과 같음) |
| `B` `Esc` | 블랙 · 복구 (지금과 같음) |

⚠️ **지금 `←→` 는 송출 중인 덱을 움직입니다.** 목록에서 펼치기/접기로 쓰면 그 기능이
목록에 있는 동안 사라집니다. 아래 ②에서 확인이 필요합니다.

## 5. 줄마다 템플릿

지금 `CueItem.templateId` 는 **저장은 되지만 쓰이지 않습니다** — 송출할 때 아무도 읽지 않아
항상 '지금 선택된 템플릿'으로 나갑니다.

- 각 줄에 템플릿 이름을 **드롭다운**으로 보여 주고, 바꾸면 그 항목에 저장합니다.
- 송출할 때 그 항목의 템플릿이 있으면 **먼저 `template:set` 을 보내고** 슬라이드를 올립니다.
- 지정하지 않은 항목은 **지금 선택된 템플릿**을 그대로 씁니다(현행 동작 유지).

**단위는 '항목'을 권합니다.** 성경 12장짜리를 슬라이드마다 다르게 두면, 본문을 고치거나
화면 넘김을 바꾸는 순간 슬라이드 수가 달라져 **어느 슬라이드에 물린 설정인지 어긋납니다**
(슬라이드는 저장되지 않고 올릴 때마다 다시 만들어집니다). 항목 단위는 그 문제가 없습니다.

## 6. 구현 순서

| 단계 | 내용 | 위험 |
|---|---|---|
| **T-1** | 한 열 레이아웃 + 펼치기/접기 (읽기 전용) | 중간 |
| **T-2** | 클릭 규칙 정리 (한 장 항목 = 바로 송출) | **높음 — 예배 중 오조작** |
| **T-3** | 키보드 재배치 (`←→` 펼치기/접기) | **높음 — 손에 익은 조작 변경** |
| **T-4** | 줄마다 템플릿 표시·변경·저장 + 송출 시 적용 | 중간 |

각 단계는 독립 커밋이고, 끝날 때마다 `npx tsc --noEmit && npx vitest run && npx vite build`
를 통과해야 합니다.

## 7. 확인이 필요한 것

| # | 질문 | 권장 |
|---|---|---|
| ① | 한 장짜리 항목(광고·순서 표시·공백)을 **클릭하면 바로 송출**해도 될까요? 1차의 "눌러도 안 나간다"가 바뀝니다 | **예** — 대신 여러 장 항목의 머리 줄은 펼치기만 |
| ② | 목록에서 `←→` 를 **펼치기/접기**로 쓰면, 송출 덱 이동은 `Space`·`PgDn/PgUp`·하단 버튼만 남습니다. 괜찮을까요? | **예** (`Shift+←→` 를 덱 이동으로 남겨 둘 수도 있습니다) |
| ③ | 템플릿 지정 단위를 **항목**으로 할까요, 굳이 **슬라이드**마다 둘까요? | **항목** (§5 사유) |
